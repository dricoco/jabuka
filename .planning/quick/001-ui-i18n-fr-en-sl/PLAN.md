# Quick 001: tablet UI in French / English / Slovenian + one-command local demo

Asked by the owner: "on peut mettre l'interface tablette en francais anglais slovene ?" then
"ok vas-y". He also wants to try the stack locally in a desktop browser.

## Part A: language switch (FR / EN / SL)

1. `static/i18n.js`, the only file holding UI text:
   - `t(key, params)`: `{name}` placeholders. Fallback chain: the current language, then fr,
     then the key itself.
   - `DICT = {fr, en, sl}`. fr is the source and the default.
   - `getLang()` and `setLang(lang)`. The language is stored per device in localStorage
     `jabuka.lang`, inside try/catch with fr as the fallback. Node has no localStorage, so it
     gets fr and the existing node tests stay unchanged.
   - `fmtDec(x, digits)`: a decimal comma for fr and sl, a point for en.
   - `trServer(text)`: translates the core's French strings on the client (alerts, route reasons,
     the banner). It uses an exact table, then ordered regex rules whose captured reasons are
     translated recursively. Unknown text is shown as-is. In fr the text always stays exactly as
     the server sent it.
   - `applyI18n(root)` handles the static markup through `data-i18n`, `data-i18n-aria` and
     `data-i18n-title` attributes (index.html, diag.html).
2. Every visible string in the JS files moves to keys:
   - app (tabs, night, wake, link and map badges)
   - helm_logic (labels, hints, countdown, units, source badge, flags)
   - route_logic (`STR` becomes a getter proxy on `route.*` keys; reasons go through
     `trServer`) and route.js
   - carte (panel, sheets, banner)
   - reglages (manual wind, status lines, settings labels by field key with the server label as
     fallback, enum option labels)
   - lock, diag.html/diag.js/diag_logic.js
   - the helm alert badges (`navAlerts` goes through `trServer`)
3. Réglages gets a "Langue / Language / Jezik" row with FR / EN / SL buttons. A switch saves the
   choice, notes the open tab in sessionStorage and reloads the page. This is far simpler and
   more robust than re-rendering every mounted module. The lock and night state are in
   localStorage, so they survive the reload. Réglages cannot be reached while locked.
4. `docs/I18N-SL-REVIEW.md`: a key | fr | sl table for the Slovenian skipper to proofread. It is
   generated by `python -m jabuka.tools.i18n_review`, and a test keeps it in sync.
5. Tests:
   - `tests/test_i18n.py` (node):
     - Key completeness: the three languages have the same keys, no value is empty, and every
       language uses the same placeholders. Every Settings field has a label key.
     - A heuristic scan for French literals in the JS files (comments stripped, allowlist of
       server values and internal IDs).
     - Alert coverage: every alert and reason string the core emits (collected from the Python
       sources plus samples of the patterns) is translated in en and sl and stays identical in fr.
     - en/sl formatting of helm and route values.
     - The review doc is up to date.
   - `tests/ui/test_i18n_ui.py` (Playwright): switch to sl, then en.
     - Key labels change and the choice survives a reload.
     - The lock and night mode still work.
     - In sl, the helm bands do not overflow at 1280x800 and 800x1280.
   - The existing UI tests stay unchanged. `tests/test_diag_logic.py` runs its English assertions
     under `setLang("en")`, because the diag page becomes French by default like the rest.

## Part B: `python -m jabuka.tools.demo` / `scripts/demo.sh`

- Reuse rehearsal.py:
  - `write_boat_pack` gains optional `twd`/`tws`/`shift_deg_h` parameters.
  - `BoatStack` gains optional `root`/`http_port`/`http_host` parameters.
  - The synth argument list moves into a shared `synth_args()`.
  - Rehearsal behaviour is unchanged: same arguments, same defaults.
- The pack goes in `var/demo/racepack`, one directory, because the core reads map and routing
  files from the same `--racepack`. It holds:
  - the map files from `var/racepack/` when present, else `tests/fixtures/map/sibenik.pmtiles`
    plus the mini seamarks
  - the rehearsal land mask
  - a slowly veering wind (6°/h by default), the same wind the synth sails in
- Process order:
  1. `jabuka-core` (`--clock sim`, the synth's gpsd), port 8080 by default, on 127.0.0.1, or on
     0.0.0.0 with `--lan`
  2. `jabuka-sim` (pty, fake gpsd, `--follow` on the core, so the helmsman beats to Plić Sestre
     and tacks at the laylines), `--speed 2` by default
  3. `jabuka-ingest-fastnet`
- The Host check already accepts localhost and IP literals, so the core is not touched.
- The demo prints the URLs in French and stays in the foreground. Ctrl-C (or SIGTERM) stops all
  children. `var/demo/` is reset on every start, but only if it carries the demo marker.
- Test `tests/commissioning/test_demo.py`:
  - Starts the demo on a free port in a tmp dir.
  - Waits for LIVE wind and route state ok (bounded).
  - Sends SIGINT and checks that no process mentioning the tmp dir is left.
- README: a "Tester en local" section.
