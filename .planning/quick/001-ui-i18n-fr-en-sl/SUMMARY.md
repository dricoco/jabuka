# Quick 001: tablet UI in FR / EN / SL, plus a one-command local demo

Part A:
- static/i18n.js: t, getLang/setLang (localStorage, try/catch, fr fallback), fmtDec, applyI18n,
  and trServer for the core's alerts, reasons and banner. About 320 keys per language.
- Every visible string moved to keys.
- Réglages: FR/EN/SL buttons; a switch reloads the page back on Réglages.
- docs/I18N-SL-REVIEW.md (key | fr | en | sl), generated by jabuka.tools.i18n_review and kept
  in sync by a test.

Part B:
- jabuka.tools.demo / scripts/demo.sh start jabuka-core (sim clock, 127.0.0.1:8080, --lan),
  jabuka-sim (pty, fake gpsd, --follow --follow-route, ×2 speed, wind veering 6°/h) and
  jabuka-ingest-fastnet.
- Race pack: the real map from var/racepack/ (else the test map), the rehearsal land mask, and a
  wind.npz matching the synth's wind.
- var/demo/ is wiped only when it carries the demo marker; Ctrl-C stops every child.
- On this laptop the first route takes about 2 s, and the boat tacks where the route says.

Deviations: the opt-in --follow-route; the diag page is French by default (test_diag_logic uses
setLang("en")); fr enum labels and a decimal comma for the Carte radius; an extra en column in
the review sheet; tools write through atomic_write_bytes.
