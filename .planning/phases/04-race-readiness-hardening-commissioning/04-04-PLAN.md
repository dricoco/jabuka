jabuka.soak.report:
- FINGERPRINT_ALGO = "sha256sum-v1".
- FINGERPRINT_SH = "find . -type f ! -name '*.pyc' ! -path '*/__pycache__/*' -print0 | LC_ALL=C sort -z | xargs -0 sha256sum | sha256sum". Run inside the package dir, its hex is the fingerprint.
- fingerprint_entries(entries: Iterable[tuple[str, bytes]]) -> tuple[str, int]. Each entry is (relpath relative to the package dir, POSIX separators, content). The function:
  - skips entries with a "__pycache__" path component or a ".pyc" suffix;
  - builds the line "<sha256hex(content)>  ./<relpath>\n" (two spaces) for each remaining entry;
  - sorts the lines by the UTF-8 bytes of "./<relpath>";
  - returns (sha256 hex of the concatenated UTF-8 manifest, number of entries kept).
- package_fingerprint(pkg_dir: Path) -> dict {"sha256", "files", "package_dir"}. It walks regular files only (symlinks skipped, as `find -type f` does) and raises CodeIdentityError on unreadable files.
- class CodeIdentityError(Exception).
- locate_package(python: str) -> Path runs [python, "-I", "-c", <print importlib.util.find_spec('jabuka').submodule_search_locations[0]>] with a 60 s timeout. Any failure raises CodeIdentityError with the reason. It is used only outside system scope.
- venv_package(bin_path: str | Path) -> Path takes venv = Path(bin_path).parent.parent and requires exactly one match of venv.glob("lib/python3*/site-packages/jabuka/__init__.py"); it returns that match's parent and raises CodeIdentityError otherwise. It executes nothing (system scope, root).
- code_identity(pkg_dir: Path, *, python: str | None, source: str, units: dict[str, str] | None = None) -> dict {"algorithm", "sha256", "files", "package_dir", "python", "source", "units"}. source is "units" (system scope) or "children" (shim/user); units maps unit name to sha256 hex, system scope only.
