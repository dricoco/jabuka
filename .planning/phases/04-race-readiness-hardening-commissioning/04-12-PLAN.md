- down: unchanged.
- up(t, pointerId) -> boolean:
  - false when not pressing or another pointerId (the press continues);
  - otherwise d = t - start, the press clears, and the result is true (latching unlocked) iff holdMs <= d <= maxMs.

- progress(t): 0 when not pressing or t - start > maxMs, else min(1, max(0, (t - start) / holdMs)).
- ready(t) -> boolean: pressing and holdMs <= t - start <= maxMs.
