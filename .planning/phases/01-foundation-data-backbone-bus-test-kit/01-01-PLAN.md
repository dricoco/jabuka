## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| B&G bus → /dev/fastnet → ingest | Untrusted, possibly garbage bytes from the bus (or a replay file). The only path back toward the bus is the serial fd. |
| ingest/replay/sim → core (UDP 127.0.0.1:47100) | Datagrams from local processes. Any local process could send malformed or forged JSON. |
| Browser on the AP → core HTTP/WS | Any client that joined the Wi-Fi can read diagnostics and POST /api/event. |
| Core → disk (logs, state files) | Power cuts mid-write; disk exhaustion over 36 h. |
