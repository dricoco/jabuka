## Phase Goal

**As the** helmsman of the X35 (the owner, racing at night), **I want to** race to the next mark on laylines alone, with polar targets, live laylines and the course on a night-readable tablet helm view over an offline map, from live or manually entered wind, **so that** I have a guaranteed "steer this / tack here" even if routing never ships.

## Acceptance Criteria (this plan)
- [ ] Night mode is true black/red across map, overlays and numbers, persisted per tablet
- [ ] The helm map shows boat, course, marks with radii, laylines and seamarks; course-up/north-up and boat-centred work
- [ ] The big numbers follow the point of sail with deviation, targets, % polar, DTW/TTW, countdown, other-tack heading and badges; frozen data is never shown as live
- [ ] Lock mode survives spray; the screen stays awake, with the tablet setup documented
