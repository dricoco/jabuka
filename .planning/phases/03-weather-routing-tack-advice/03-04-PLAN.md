## Phase Goal

**As the** helmsman of the X35 racing Regata Jabuka through the night, **I want to** follow an optimal route to the remaining marks that keeps updating from GRIB wind corrected by live measurements, never crosses an island or shoal, and tells me when to tack, whether staying on this tack is acceptable and what not tacking costs, **so that** I sail the fastest safe course without routing in my head, while the Phase 2 laylines stay the fallback.

## Acceptance Criteria (this plan)
- [ ] A followed route yields target TWA/tack, heading from the live TWD and a route-time countdown; a missed tack is flagged once, 2 min late
- [ ] The bias estimator learns only in steady sailing, clamps, fades, freezes at Jabuka and accepts a manual observation
- [ ] Reroute triggers and hysteresis are explicit, tested decisions; the worker pool survives hangs and crashes on 3.13 and 3.14 without blocking the loop

<objective>
Build the decision logic of the tack advice and the bias, and the process pool the router runs in, as pure, clock-injected Python with no numpy and no dependency on Phase 2 modules, so the core integration (03-05) only wires inputs and outputs.

Purpose: "stable and actionable" advice (CONTEXT §Tack advice, §Supervisor) is mostly state machines and thresholds; testing them on synthetic sequences now removes risk from the late integration, and the pool proves the Pi's 3.13 fork default and the kill path before any real routing runs in it.
Output: src/jabuka/route/{advice,bias,pool,pool_probe}.py and their tests.

This plan runs before Phase 2 merges and touches no Phase 2 file. It needs no third-party package (stdlib + jabuka.common only), so its tests run in every venv.
</objective>
