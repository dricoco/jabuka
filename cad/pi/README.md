# Boîtier Pi (Raspberry Pi 3B + écran Waveshare 3,5" + powerbank Silicon Power QX55)

`x35_pi_box.py` / `build_pi.py` (`freecadcmd -c "exec(open('build_pi.py').read())"`) → `../../stl/pi/` :
`Boitier.stl` (debout sur le fond, sans support), `Barre_powerbank.stl` et `Barre_pi.stl` (à plat).
Visserie : 4 × M3 × 12 tête fraisée + 4 écrous M3.

Le fourreau du Pi n'est pas dans le dépôt (licence CC BY-NC) : imprimer *Body* et *End Cap* de
« Raspberry Pi Case and Adjustable Stand for Waveshare 3.5" RPi LCD (B) » par srwilson58,
https://www.thingiverse.com/thing:3473751 , sans modification. Longueur assemblée 87,4 mm (mesurée sur les STL).
